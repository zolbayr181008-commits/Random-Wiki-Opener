# 🎲 Random Wiki Opener

A simple tool that opens a random Wikipedia article in your default web browser.

## ✨ Features

- Opens random Wikipedia articles
- Uses your default browser
- Lightweight and simple
- Easy to run on Linux

## 🛠️ Requirements

- Linux
- Bash
- curl
- A web browser

## 🚀 Installation

Clone the repository:

    git clone https://github.com/zolbayr181008-commits/Random-Wiki-Opener.git

Enter the project directory:

    cd Random-Wiki-Opener

## ▶️ Usage

Run the script:

    bash random-wiki-opener.sh
